# YOLOHome Website

YOLOHome là hệ thống giám sát và điều khiển thiết bị trong nhà, gồm backend API + giao tiếp MQTT để kết nối gateway/thiết bị IoT.

## Cấu trúc thư mục

```text
YOLOHome-Website/
├─ backend/     # Node.js + Express + MongoDB + MQTT
└─ frontend/    # Frontend app
```

## Tài liệu chính

- Backend setup: xem `backend/README.md`
- API chi tiết: xem `backend/API_DOCS.md`
